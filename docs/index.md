# Testbedimage

Testbedimage helps to import data from the image-repository into the OpenStack image service. It can also deploy images from the OpenStack image service to an image-repository (SFTP).

## Getting started

Check out the [Installation](installation.md) guide to set up the tool, and then proceed to [OpenStack Configuration](configuration.md) to configure access to your OpenStack project.

## Usage

- [Import Images](import.md)
- [List Images](list.md)
- [Delete Images](delete.md)
- [Print Manifest](manifest.md)
- [Deploy Images](deploy.md)
