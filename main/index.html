Testbedimage

Testbedimage helps to import data from the image-repository into the OpenStack image service. It can also deploy images from the OpenStack image service to an image-repository (SFTP).

Getting started

Check out the Installation guide to set up the tool, and then proceed to OpenStack Configuration to configure access to your OpenStack project.
